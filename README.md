# Treehouse Restaurant — Spec Landing Page

A ready-made website built speculatively for Treehouse Restaurant, an outdoor dining spot in Accra, Ghana. The page doubles as a pitch: a closing section invites the owner to claim the site.

**Live demo:** https://yooku98.github.io/landingpage/

## What's on the page

- Hero and intro
- Highlights: outdoor seating, drinks, entertainment
- Menu, accessibility info, and "perfect for" occasions
- Video clips of the venue
- Contact via WhatsApp
- "This page was built for you" claim-this-site section (WhatsApp call-to-action)

## Stack

A single `index.html` with inline CSS and JavaScript (Google Fonts: Syne, DM Sans). No build step.

## Structure

```
index.html   Page markup, styles and script
media/       Logo, venue videos (mp4) and imagery (webp)
```

## Run locally

```bash
python3 -m http.server 8000
```

## Deployment

Served by GitHub Pages from the root of `main`.
